Registers

    B - Base            - General purpose storage
    C - Couter          - Loops, counters
    D - Data            - IO related use
    ESI -   Source idex  - Source addres, memory operation
    EDI -   Destination index  - Destination Address
    ESP -   Stack Pointer        - Point to the top of the stack 
    EIP -   Instruction Pointer   - Address to next Instruction
